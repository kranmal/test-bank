# Test Bank

A fictional, modern UK high-street-style demo bank built as a single-file HTML/CSS/JS app. Made for UI practice and test automation. No real money, no real data.

- Hash-routed SPA, data saved in `localStorage`
- Demo login: `john` / `demo`
- Accounts with 3 months of random transactions and a statement month selector
- Product, Loans & credit, Business, Private & offshore, About us and Find a branch (map) pages
- Photos from [Pexels](https://www.pexels.com/), map data © OpenStreetMap contributors

Run locally:

```bash
python3 -m http.server 8770
```

Then open http://localhost:8770.
